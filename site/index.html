Rucas

Rucas is a small esoteric programming language in the spirit of Brainfuck, but with readable assembly-style mnemonics. A program works on a tape of 30,000 cells and a stack, and it has loops, IF blocks and console I/O. It was written in 2018, and in 2026 it learned to multiply, divide and choose, and now runs small neural networks written in Rucas itself.

This page runs the real interpreter, rucas.cpp, built to WebAssembly. The repository has the full description.

Instructions


One instruction per line, a # starts a comment. An argument is a number N, $CELL for the current cell, or $STACK for the top of the stack; left out, it is 1. Cells hold 0 to 255 and wrap, unless a BITS 16 or BITS 32 line comes first.



The 26 instructions

InstructionWhat it does



ADD, SUBAdd to, or subtract from, the current cell


JMPR, JMPLMove the pointer right or left


JMPMove the pointer to a cell number


PRNTA, PRNTDPrint cells as characters, or as numbers


CINPRead one character of input into the current cell, 0 at the end


STLP, NDLPLoop while the current cell is not 0


IFRun the block if the argument, by default the current cell, is more than 0


IF EQL, IF LESS, IF MORERun the block if the current cell is equal to, less than or more than the argument


ELSE, ENDIFWhat runs when the IF does not, and the end of the block


HALTStop the program


PSHSPush the current cell onto the stack


CLRS, RMVSClear the stack, or remove its bottom value


EQL TOPSSet the current cell to the top of the stack


ADDS, SUBS, MULS, DIVS, MODSPush the top and the value below it added, subtracted, multiplied, divided or as a remainder
